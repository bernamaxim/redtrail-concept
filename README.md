# RedTrail Concept Sketch

Live tracking concept for a Marswalk at Jezero Crater: crew positions, geofence alerts,
O₂ margin, position error without GPS, and the Mars–Earth signal delay.

- Live page: published by GitHub Pages on every push to `main`.
- Run locally: open `index.html` in a browser, or `docker compose up -d --build` → http://localhost:8081
